# DSA Project: Data Structures & Algorithms in Java

A growing collection of **Data Structures and Algorithms (DSA)** projects built in Java. Every project solves a small real-world problem using a core DSA concept: sorting, searching, hashing, sliding window, two pointers, and more. New builds are added regularly, so ⭐ **star** and 👀 **watch** this repo to follow along.

## 📂 Projects

| Project                                      | What it does                                                                        | DSA concepts                                             |
| -------------------------------------------- | ----------------------------------------------------------------------------------- | -------------------------------------------------------- |
| [`contact_sorter.java`](contact_sorter.java) | Console app: enter names, sort them, then search for a contact                      | Quick Sort (recursive), Binary Search, Arrays, ArrayList |
| [`Text_toolkit.java`](Text_toolkit.java)     | Text utilities: palindrome check and longest substring without repeating characters | Two Pointers, Sliding Window, HashSet, Strings           |

More coming soon (see the [Roadmap](#-roadmap)).

## 🚀 Getting Started

**Requirements:** Java 17 or newer (JDK).

```bash
git clone https://github.com/gaur-j/dsa_project.git
cd dsa_project

# Contact Sorter
javac contact_sorter.java
java contact_sorter

# Text Toolkit
javac Text_toolkit.java
java Text_toolkit
```
